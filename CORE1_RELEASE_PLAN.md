# TechOps v1 — Core 1 Release Standard

TechOps v1 is Core 1 first. The release target is CompTIA A+ Core 1 (220-1201), Exam Objectives Version 2.0.

## Definition of Core 1 complete

TechOps v1 is not considered Core 1 complete until all 27 objectives across the five Core 1 domains are mapped to repeatable gameplay and validated in the Core 1 coverage matrix.

- 1.0 Mobile Devices — 13%
- 2.0 Networking — 23%
- 3.0 Hardware — 25%
- 4.0 Virtualization and Cloud Computing — 11%
- 5.0 Hardware and Network Troubleshooting — 28%

## Repeatable Computer Lab stations

1. PC Build Bay — RAM, storage, motherboards, CPU, expansion, power, POST, drive/RAID.
2. Cable Wall — network/peripheral/video/storage cables, connectors, termination/testing tools.
3. Network Rack — ports/protocols, wireless, host services, DNS/DHCP/VLAN/VPN, hardware, SOHO, connection types and tools.
4. Mobile Clinic — mobile hardware, accessories, wireless/cellular, Bluetooth, MDM, synchronization and mobile troubleshooting.
5. Display Lab — display technologies/attributes plus monitor/projector troubleshooting.
6. Printer Shop — deployment, configuration, maintenance and troubleshooting across printer technologies.
7. VM / Cloud Sandbox — virtual machines, containers, VDI, hypervisors, cloud models and cloud characteristics.
8. Troubleshooting Arena — mixed evidence → cause → fix → verify simulations for objectives 5.1 through 5.6.

## Learning design rules

- Fun first, but gameplay must map back to current Core 1 objectives.
- New learners get terminology in plain English at the point of use.
- Hardware practice should behave like equipment, not like a disguised multiple-choice quiz.
- Wrong actions should explain consequences rather than simply show a red X.
- Repeatable practice remains available outside the story campaign.
- Coverage is not labeled as a guaranteed exam score.
- No brain dumps or copied protected exam questions.
