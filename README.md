# TechOps — First Shift

TechOps is a browser-based IT career training game designed to teach current CompTIA A+ concepts through simulated help-desk work rather than traditional quizzes.

## Current target

- CompTIA A+ V15
- Core 1: 220-1201
- Core 2: 220-1202

## Game philosophy

Fun first, but every mission maps to real exam objectives. Players learn by diagnosing systems, using tools, making decisions, fixing problems, verifying results, and documenting tickets.

All scenarios are original and based on published exam objectives rather than unauthorized exam dumps.

## First Shift roadmap

- Interactive Level 1 help desk campaign
- Simulated Windows workstation and command terminal
- Hardware repair bench
- Network troubleshooting tools
- Security incidents
- Ticket documentation and customer consequences
- XP, reputation, credits, progression, and mastery tracking
- Boss incidents and eventually PBQ-style exam preparation

TechOps is being built as a full browser game that happens to prepare the player for CompTIA A+ — not as a quiz app with game graphics.
